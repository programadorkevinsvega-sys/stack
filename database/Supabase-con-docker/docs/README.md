## 🚀 **Inicio Rápido**

Para comenzar con Supabase Docker:

1. **Clonar el repositorio**
2. **Copiar configuración**: `cp env.example .env`
3. **Iniciar servicios**: `make start`
4. **Acceder a Studio**: http://localhost:3000
